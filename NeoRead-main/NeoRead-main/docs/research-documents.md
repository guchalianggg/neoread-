# 研究文档编辑与多标签阅读

本地二开版支持导入和编辑 Markdown、Excel、Word；PDF / EPUB 保持原有阅读方式。现有正式安装版不被覆盖，开发版使用独立书库。

## 打开二开版

在工作区根目录双击 `启动二开版.cmd`。依赖或产物缺失时，在源码根目录运行 `pnpm build` 后重试。

开发版使用 `NeoRead Dev` 配置目录及其 `library` 书库。正式快捷方式仍打开原安装版。首次请用测试材料验收，不要把两实例同时指向同一个书库。

## 导入与编辑

论文库和图书库均可导入以下研究资料：

| 格式                | 应用内编辑                                     | 保存与下载         |
| ------------------- | ---------------------------------------------- | ------------------ |
| `.md` / `.markdown` | 富文本或 Markdown 源码；标题、列表、代码、表格 | 保持 Markdown 格式 |
| `.xlsx`             | 工作表切换、单元格编辑、表格粘贴               | XLSX 编辑副本      |
| `.xls`              | 读取二进制工作簿并编辑单元格                   | 转换后的 XLSX 副本 |
| `.docx`             | 正文、标题、列表、表格等基础富文本             | DOCX 编辑副本      |
| `.doc`              | 本地转换后在应用内编辑                         | 转换后的 DOCX 副本 |

入口包括顶部导入按钮、书库导入按钮和拖放；桌面“打开方式”参数也接受这些扩展名。双击 Markdown 或 Word 默认进入只读阅读，点“编辑”修改副本；Excel 继续进入工作表编辑器。

Windows / macOS 桌面版选中文件或拖入书库时，默认「保留原文件」，也可选「导入后移到回收站」。失败、重复入库、导入过程中发生变化，或系统不支持回收的文件会保留；不会永久删除。长 PDF 还需完成原有的入库确认。系统「打开方式」默认保留；网页上传不接触本地路径，不提供回收或同步。

## Markdown 与 Word 阅读

- 在阅读工具栏切换「窄／标准／宽」正文宽度。宽屏下可在目录弹层点图钉将它固定在左侧；窄窗口自动使用弹出目录。目录随滚动标记当前章节。Word 目录依据转换后保留的标题，不会把加粗正文当成标题。
- 按 `Ctrl+F`（macOS 为 `Cmd+F`）查找正文，`Enter` / `Shift+Enter` 跳到下一处／上一处，`Esc` 关闭。查找不会修改文档。
- 宽表格可单独横向滚动；点“展开表格”只放宽该表格。每份文档独立保留阅读位置、正文宽度和目录固定状态；位置按标题与段落恢复，原段落不存在时退回附近可用内容。
- “返回阅读”可以预览未保存的草稿，不等于保存。原件不受影响。

## 保存与导出

- 点击“保存”或按 `Ctrl+S`（macOS 为 `Cmd+S`）保存当前修改。
- “下载”取得当前已保存的编辑副本；原始导入文件始终独立保留在附件中。
- 桌面导入时保留的 `.md`、`.markdown`、`.doc`、`.docx` 会绑定原路径。在 Reader 的原文阅读界面打开文档、切回窗口或等待几秒，外部保存的变更会更新同一个书库条目。Reader 只读原路径，不把编辑写回；库内附件仍是最初导入的版本。选择移到回收站不会绑定同步。
- 已关联的 Markdown（`.md` / `.markdown`）在活动阅读页监听外部保存，不用手动重开；系统没有发出文件通知时仍定时检查。阅读位置按标题和段落尽量保留。Word 继续使用原有的检查方式。
- 阅读时可点「检查源文件」；编辑中或有草稿时暂停检查。已有 Reader 内保存的不同版本、受保护的定位数据、原文件移走或读取失败时，当前版本保留。要查看冲突的磁盘版本，可单独导入一份副本。
- 同步关联限本机和当前书库位置；移动原件或更换书库位置后不会自动猜测新路径。升级前已导入的条目没有路径记录；可从桌面重新选择内容仍相同的原文件建立关联。
- Markdown 阅读工具栏的「导出」支持 Markdown 源码（`.md`）和排版 PDF。导出当前已保存的正文，不会自动保存草稿。Markdown 输出不改写正文或打包附件；PDF 不主动读取磁盘或网络图片。
- 切换文档标签保留当前会话的编辑草稿。关闭含未保存修改的标签会提示；关闭窗口会等待编辑保存，失败时进入现有的退出确认流程。
- 发生版本冲突时不会自动覆盖较新的已保存内容。先保留本地草稿，再决定是否重新加载。
- 相同原件再次导入会定位到已有文档，不应用旧原件覆盖已保存的编辑副本。

## Word 和 Excel 的边界

Word 编辑不是完整 Office 排版引擎。支持基础正文与结构，复杂版式、浮动对象、图表、修订及其他高级对象不保证保真；原件保留用于回溯。旧 `.doc` 转换需要本机 Microsoft Word，DOCX 基础转换需要 Pandoc；本机已经检测到这两项工具，不将文档上传到外部服务。

Excel 编辑以单元格文本/数值和工作表为范围，不执行宏，不自动联网刷新外部数据，也不承诺公式重新计算或图表原样还原。旧 XLS 转 XLSX 的格式保留范围有限；修改前可先下载原件备份。

Markdown 使用 UTF-8。不自动读取源文件同目录的图片或其他文件，不联网抓取图片。超出转换/编辑规模限制时显示错误，不静默截断。

原文件下载位置：论文库详情的“附件”；图书库详情的“原文件与附件”。编辑副本使用编辑器中的下载按钮。

## 多文档标签

顶部导航栏默认开启，显示“书库”、文档标签、“＋”及导入入口。PDF、Markdown、Excel 和 Word 可以分别占用标签；重复打开同一份只激活已有标签。

点击“书库”不会关闭文档；“＋”查找下一份书库文档。支持关闭、拖动排序和恢复关闭标签。旧书库如果明确保存过关闭多标签的偏好，请在“设置 → 阅读交互 → 多文档标签页”开启。

- `Ctrl+Tab` / `Ctrl+Shift+Tab`：切换文档。
- `Ctrl+W`：关闭当前文档。
- `Ctrl+Shift+T`：恢复最近关闭的标签。
- macOS 的关闭和恢复使用 `Cmd`。

## 人工验收

1. 导入一份 Markdown，修改正文与表格，保存、关闭标签、重新打开，确认修改保留；下载编辑稿与原件，确认两者独立。
2. 导入两个工作表的 Excel，在两表修改不同单元格，保存并重新打开；下载 XLSX 检查值。
3. 分别导入 DOCX 和真实二进制 DOC，修改基础正文后保存，下载 DOCX 验证。复杂排版用自己的样本人工检查。
4. 同时打开两份 PDF 和一份汇总文档，切换并返回书库，确认标签保留、编辑草稿不串文档。
5. 模拟保存失败或版本冲突，确认错误可见、草稿保留，不显示虚假的“已保存”。
6. 检查窗口变窄、浅/深色主题、标签关闭确认及重启后的已保存内容。
7. 只读打开两份含重复标题的 Markdown 或 Word，在各自不同章节停留；验证目录固定、窗口变窄时退回弹出模式、正文搜索计数和命中高亮。关闭标签或重启后分别打开，确认位置和宽度各自恢复。
8. 桌面导入一份 Markdown 副本并选择保留。用外部编辑器保存新内容，回到 Reader 只读页，确认同一条目更新且库内原始附件不变；再在 Reader 内保存后外部修改，确认不会覆盖 Reader 的版本。
9. 用一份新的测试副本验证「导入后移到回收站」。确认入库成功后才移除，重复导入或导入失败时文件仍在原位。
10. 保留 Markdown 原文件，用外部编辑器保存或原子替换文件，确认活动阅读页收到更新，不用关闭重开。点「导出」分别保存 `.md` 和 PDF，核对两份都包含刚更新的正文。进入编辑模式后输入草稿，确认不会被外部保存覆盖。

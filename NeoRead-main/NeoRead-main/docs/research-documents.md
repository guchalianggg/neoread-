# 研究文档编辑与多标签阅读

本地二开版支持导入和编辑 Markdown、Excel、Word；PDF / EPUB 保持原有阅读方式。现有正式安装版不被覆盖，开发版使用独立书库。

## 打开二开版

在工作区根目录双击 `启动二开版.cmd`。依赖或产物缺失时，在源码根目录运行 `pnpm build` 后重试。

开发版使用 `NeoRead Dev` 配置目录及其 `library` 书库。正式快捷方式仍打开原安装版。首次请用测试材料验收，不要把两实例同时指向同一个书库。

## 导入与编辑

论文库和图书库均可导入以下研究资料：

| 格式 | 应用内编辑 | 保存与下载 |
| --- | --- | --- |
| `.md` / `.markdown` | 富文本或 Markdown 源码；标题、列表、代码、表格 | 保持 Markdown 格式 |
| `.xlsx` | 工作表切换、单元格编辑、表格粘贴 | XLSX 编辑副本 |
| `.xls` | 读取二进制工作簿并编辑单元格 | 转换后的 XLSX 副本 |
| `.docx` | 正文、标题、列表、表格等基础富文本 | DOCX 编辑副本 |
| `.doc` | 本地转换后在应用内编辑 | 转换后的 DOCX 副本 |

入口包括顶部导入按钮、书库导入按钮和拖放；桌面“打开方式”参数也接受这些扩展名。导入后双击文档，进入应用内编辑器。

- 点击“保存”或按 `Ctrl+S`（macOS 为 `Cmd+S`）保存当前修改。
- “下载”取得当前已保存的编辑副本；原始导入文件始终独立保留在附件中。
- 修改原始磁盘文件并不会自动改写书库内容；应用内编辑保存也不会覆盖原始磁盘文件。
- 切换文档标签保留当前会话的编辑草稿。关闭含未保存修改的标签会提示；关闭窗口会等待编辑保存，失败时进入现有的退出确认流程。
- 发生版本冲突时不会自动覆盖较新的已保存内容。先保留本地草稿，再决定是否重新加载。
- 相同原件再次导入会定位到已有文档，不应用旧原件覆盖已保存的编辑副本。

## Word 和 Excel 的边界

Word 编辑不是完整 Office 排版引擎。支持基础正文与结构，复杂版式、浮动对象、图表、修订及其他高级对象不保证保真；原件保留用于回溯。旧 `.doc` 转换需要本机 Microsoft Word，DOCX 基础转换需要 Pandoc；本机已经检测到这两项工具，不将文档上传到外部服务。

Excel 编辑以单元格文本/数值和工作表为范围，不执行宏，不自动联网刷新外部数据，也不承诺公式重新计算或图表原样还原。旧 XLS 转 XLSX 的格式保留范围有限；修改前可先下载原件备份。

Markdown 使用 UTF-8。不自动读取源文件同目录的图片或其他文件，不联网抓取图片。超出转换/编辑规模限制时显示错误，不静默截断。

原文件下载位置：论文库详情的“附件”；图书库详情的“原文件与附件”。编辑副本使用编辑器中的下载按钮。

## 多文档标签

顶部导航栏默认开启，显示“书库”、文档标签、“＋”及导入入口。PDF、Markdown、Excel 和 Word 可以分别占用标签；重复打开同一份只激活已有标签。

点击“书库”不会关闭文档；“＋”查找下一份书库文档。支持关闭、拖动排序和恢复关闭标签。旧书库如果明确保存过关闭多标签的偏好，请在“设置 → 阅读交互 → 多文档标签页”开启。

- `Ctrl+Tab` / `Ctrl+Shift+Tab`：切换文档。
- `Ctrl+W`：关闭当前文档。
- `Ctrl+Shift+T`：恢复最近关闭的标签。
- macOS 的关闭和恢复使用 `Cmd`。

## 人工验收

1. 导入一份 Markdown，修改正文与表格，保存、关闭标签、重新打开，确认修改保留；下载编辑稿与原件，确认两者独立。
2. 导入两个工作表的 Excel，在两表修改不同单元格，保存并重新打开；下载 XLSX 检查值。
3. 分别导入 DOCX 和真实二进制 DOC，修改基础正文后保存，下载 DOCX 验证。复杂排版用自己的样本人工检查。
4. 同时打开两份 PDF 和一份汇总文档，切换并返回书库，确认标签保留、编辑草稿不串文档。
5. 模拟保存失败或版本冲突，确认错误可见、草稿保留，不显示虚假的“已保存”。
6. 检查窗口变窄、浅/深色主题、标签关闭确认及重启后的已保存内容。

# 本地编辑二开版验证记录

## 交付范围

- Markdown（MD / MARKDOWN）：应用内富文本/源码编辑、保存与下载。
- Excel（XLSX / 二进制 XLS）：多工作表、单元格编辑与表格粘贴；保存 XLSX 编辑副本。
- Word（DOCX / 二进制 DOC）：基础富文本编辑；本地转换并保存 DOCX 编辑副本。
- 顶部多文档标签默认开启；重复打开去重、切换保留当前会话草稿。
- 导入原件独立保留，不覆盖原始磁盘文件。保存带修订号冲突检查，失败保留草稿。
- 开发版不覆盖原安装版，使用独立的 `NeoRead Dev` 配置和书库。

## 不应误解为已完成的检查

- 没有使用浏览器自动化进行视觉验收。复杂文档、长表格、窄窗口、深浅色和实际操作体验仍按 `research-documents.md` 人工验收。
- Word/Excel 是基础内容编辑，不是完整 Office 排版引擎；公式重算、图表、复杂版式等不承诺保真。原件保留用于回溯。
- 此前全量 TS 测试运行记录为 1869 项通过、15 项失败、55 项跳过，包含 Windows 符号链接权限、Python 不可用及超时等问题。本次定向回归不能被描述为全项目测试全绿；未扩大范围修复这些其他模块。
- 不是正式安装包发布：未修改原安装版、未自动迁移正式书库，源码是 ZIP 解压版，没有 Git 仓库/提交记录。构建提示无法读取 Git 提交号不影响已返回 0 的构建结果。

使用入口：工作区根目录 `启动二开版.cmd`。操作步骤与已知范围见 `research-documents.md`。
